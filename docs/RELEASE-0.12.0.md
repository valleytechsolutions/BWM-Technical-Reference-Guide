# Black Wire 0.12.0 — Wiring & protocols

Find a connection diagram alongside your board pinout. This release adds a dedicated wiring desk, unified protocol search and 15 wiki guides using collection **2026.09.12**.

- RJ45 / 8P8C T568A/B, telephone USOC terminals, UART, RS-232, RS-485, CAN, I2C, SPI, SWD and JTAG.
- RFID/NFC roles and module-specific ELECHOUSE ST25R3916B SPI/I2C, PN7160 MINI V1 I2C and PN532 V3 interface selection.
- Fifteen original SVG diagrams with zoom, download, readable connection tables, practical checks, manufacturer links, revision scope and CC BY 4.0 credits.
- Matching module records open their original images and documents. Protocol guides are searchable without being counted as physical board pinouts.

The electrical examples are documentation-based and have not been independently bench-tested. Exact connector views, hardware revisions, logic levels and mode settings still matter. This adds no new verified Power Desk ratings. The annual editorial edition remains **First Edition / 2026**; the book draft is unchanged.
