# Browser/source update 0.15.1

Reference titles and action buttons could overlap at phone widths, pushing the close button outside the visible dialog. The reference header now places actions below the title and wraps the buttons within the dialog. A 390-pixel browser regression verifies separation and an accessible close button.

The guide uses collection 2026.10.2: 10 new records, 124 enriched records, 232 reference attachments and 159 external pin-purpose rows. First Edition / 2026 is unchanged. The native renderer and browser are built from this source; no new native installer is distributed. Published desktop installers remain 0.14.0, with their original catalog and signing status.
