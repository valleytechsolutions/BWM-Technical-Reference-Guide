# Help improve the maker reference

Report errors, contribute sources and request hardware with enough evidence to review.

## Report a reference problem

Use the pinout collection for incorrect labels, wrong models, missing sources or missing boards. Include the exact device and revision, guide record link, what appears wrong and manufacturer evidence. Identify the connector, pin or callout involved. Exclude private measurements and personal information.

[Report a reference issue](https://git.churchofmalware.org/Valleytech/black-wire-pinouts/issues)

## Contribute a useful source

- Prefer manufacturer documentation, original schematics, maintained board repositories or clearly identified original hardware evidence.
- State the model, revision, view orientation and connector scope.
- Include the source URL, author, license and collection date where known.
- Mark uncertainty and missing pins. Keep original image bytes and attribution.
- For a custom diagram, provide editable source and a per-pin evidence trail.



## Report an application problem

For broken search, display issues or desktop bugs, state the app version, platform, exact steps and expected result. Include the theme and window size for layout problems. A minimal reproducible report helps test the correction.

[Report an app issue](https://git.churchofmalware.org/Valleytech/BWM-Technical-Reference-Guide/issues)

## Suggest a practical improvement

Describe the workbench task and where the guide slows you down. Failed search terms, hard-to-read diagrams and missing revision distinctions are especially useful. Hardware requests join the research queue; a request does not mean its pinout is already verified.
