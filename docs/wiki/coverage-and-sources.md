# Coverage, sources and review status

What each coverage label means and where the remaining documentation gaps are recorded.

## Read the label before the diagram

- Pinout source: a physical map is present. Read its scope and revision; this is not an all-pin approval.
- Pin functions · map needed: signal-purpose information exists, but a physical map is still needed.
- Pinout needed: supporting references exist without a qualifying physical pinout.
- Documentation needed: no suitable local reference has yet been collected.



## Evidence travels with the reference

Records carry model and revision notes, source URLs, review status and hashes where recorded. Some maker records describe manufacturer families or unidentified generic variants. These distinctions stay visible. Original art is not silently relabeled to represent a different product.



## An expanding collection

Directory counts describe this catalog snapshot, including family records and shared references. They are not a worldwide inventory or a count of fully verified devices. The coverage audit records remaining work.

[Current pinout coverage audit](https://git.churchofmalware.org/Valleytech/black-wire-pinouts/src/branch/main/PINOUT_COVERAGE.md)

## Artwork and reuse

Manufacturer images keep their source and rights notes. The app’s code license and the guide’s original-text license do not relicense third-party artwork. A public download or removed logo does not establish permission to reuse an image. Consult its recorded rights and original license before redistribution.



## Edition and version

First Edition / 2026 is the editorial edition. App releases and dated collection snapshots are versioned separately. Interface improvements do not create a new book edition.
