# October brand sweep: new references and open gaps

Collection 2026.10.5 adds 16 board/device records and 16 maker records with original manufacturer references.

## New physical maps

XIAO STM32C5 front and back maps, PaperDIY FPC connector references, three 01space development boards, and W6100-EVB-Pico/Pico2 are now searchable. These contribute nine physical-pinout image entries. Some additions are older omissions, not newly launched hardware.



## More useful board documentation

Sixteen Adafruit sensor and interface breakouts include saved hardware-guide PDFs, schematics and labeled PCB layouts. Additional records cover W6300 Pico variants, LILYGO T-Dongle-S3-Dual/Plus, Raspberry Pi Compute Module Zero, Radxa X5/Cubie A7S, Inventor 2350 W and SparkFun IoT RedBoard RP2350. Physical maps still need verification for those supporting-document records. Search by exact model and check the reference-type label.



## What the sweep establishes

Source discovery was attempted for all 163 existing brand labels. That includes aliases, resellers and unidentified manufacturers; it is not proof of a complete worldwide inventory. The public register records retrieval gaps and follow-up work. W6300 physical maps are explicitly marked coming soon by WIZnet. A chip datasheet or photograph never substitutes for a board pinout.
