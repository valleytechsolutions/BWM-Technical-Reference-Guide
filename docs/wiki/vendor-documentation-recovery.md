# Manufacturer manuals, schematics and pinout gaps

Collection 2026.10.4 expands Waveshare, M5Stack and NodeMCU documentation while keeping the limits of each source clear.

## More source documents beside each board

571 reference attachments enrich 416 existing listings: 555 PDFs, nine physical-pinout entries, five GPIO function diagrams and two full-page connector tables. The collection now contains 4,457 board reference entries and 1,599 physical-pinout entries. Listing counts include historical and assembly aliases, not unique hardware.



## Read the exact document scope

NodeMCU DevKit 0.9 and 1.0 gain official board schematics. ToughC5 and Unit 8Servos2-I2C have saved manufacturer hardware guides. ATOM Lite, StampS3A, Nesso N1 connectors and several Waveshare boards gain physical maps. A module within a kit, a connector table and a full-device map are labeled separately. Match the pictured revision before wiring.

## Datasheets are not interchangeable

A manufacturer manual may provide specifications without being a separate board datasheet. The ESP32-C5 chip datasheet is identified as component documentation, never as a board power specification. A Waveshare file named ESP32-P4-Pico-datasheet.pdf contains a schematic and is classified by its contents. ToughC5 still lacks a verified whole-device physical map; NodeMCU ESP32-C2 hardware provenance remains unresolved.



## Originals and viewing performance

The four Nesso N1 images are unusually large. Smaller screen previews make them practical to browse; Save original retains their full source resolution. All new originals have recorded source URLs, SHA-256 hashes and review/rights labels. Electrical verification and permission to print manufacturer artwork remain separate work. First Edition / 2026 is unchanged.
